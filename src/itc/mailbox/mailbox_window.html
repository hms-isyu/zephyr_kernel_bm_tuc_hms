mailbox measurement window: switches between T_HIGH, T_LOW, T_ARM

One steady-state transaction per scenario, time running downward. A horizontal arrow is a switch of the running task; its label is the call that issues it. Arrows inside the window are numbered. T_ARM is the control task (T_ArmUp, T_ArmDown). Zephyr: a lower number is a higher priority.

switch issued by a semaphore call switch issued by the ITC primitive measurement window, START to STOP faded: switch outside every window byte copy of the message size

self is not drawn: T_SELF is sender and receiver at once, and its window holds no switch.

Drawn from the test sources in src/itc/mailbox and zephyr/kernel (mailbox.c, sem.c). The first transaction after a scenario starts also passes k_event_wait_safe(); the steady state is shown.
