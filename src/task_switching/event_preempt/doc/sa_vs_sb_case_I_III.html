Both scenarios hold the same number of waiters at each point: S_A has H_Task_SA plus the dummies, S_B has L_Task_SB plus the dummies. Adding a dummy moves both sides onto the two-node fetch at walk +08c together and gives both a second wake, so those costs appear in both columns. What is left in the difference is the swap and the position each woken thread takes in the run queue.
